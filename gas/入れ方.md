# メール送信の係（GAS）の入れ方　2026/10/21（部品の版。「〇〇」はお店の名前に読みかえる）

予約が入ったとき、**お店の Gmail から**「お客さんへ確認メール」と「お店へ知らせ」を送るしくみです。
Google Apps Script（GAS。Google の中で動く小さなプログラム）を、**お店の Google アカウント**に入れます。所要 10 分ほど。
パスワードはここに書きません。打つのはお店の人（か担当者）です。

用意するもの：パソコンの Chrome・このフォルダの `gas/appsscript.json` と `gas/Code.gs`・合言葉（担当者が決めた文字列。Cloudflare の GAS_TOKEN と同じもの）

**先に：シークレット ウィンドウ（かゲスト）で始める**
Chrome に Google アカウントが2つ以上入っていると、許可のあとに「ファイルを開くことができません」と出て止まります（10/21 に実際に起きた）。
Chrome の右上「︙」→ **「新しいシークレット ウィンドウ」**（⌘⇧N）を開き、その中で https://accounts.google.com/ に **お店の Google だけ** でログインしてから、下の 1 から始めてください。途中で止まったら、シークレット ウィンドウを閉じて最初からやり直すのがいちばん早いです。

## 1. 新しいプロジェクトを作る
1. シークレット ウィンドウで https://script.google.com/ を開く（右上がお店の Google になっているのを確かめる）
2. 左上の **「＋ 新しいプロジェクト」** を押す
3. 左上の「無題のプロジェクト」を押して、名前を **「〇〇 予約メール」** にして「名前を変更」

## 2. 先に appsscript.json を貼る（許可を「メールの送信」だけにする）
Code.gs より **先に** これをします。あとからだと、許可の画面で「Gmail のすべてのメールを閲覧・作成・送信・削除」まで求められます。
1. 左の歯車 **「プロジェクトの設定」** を押す
2. 「全般設定」の **「『appsscript.json』マニフェスト ファイルをエディタで表示する」** にチェックを入れる
3. 左の **「＜＞ エディタ」** に戻ると、ファイルの一覧に **appsscript.json** が出ている → それを押す
4. 中身を**全部消して**、`gas/appsscript.json` の中身を**全部コピーして貼る** → 保存（⌘S）

## 3. Code.gs を貼る
1. ファイルの一覧の **コード.gs** を押す。編集画面に `function myFunction() { }` と出ている → **全部消す**
2. `gas/Code.gs` の中身を **全部コピーして貼る**（Mac：ファイルを開いて ⌘A → ⌘C → 編集画面で ⌘V）
3. 上の **フロッピーの印（保存）** を押す（⌘S でもよい）

## 4. 合言葉を入れる（スクリプト プロパティ）
1. 左の歯車 **「プロジェクトの設定」** を押す
2. いちばん下の **「スクリプト プロパティ」** → **「スクリプト プロパティを追加」**
3. プロパティ：`GAS_TOKEN`　値：合言葉（担当者から聞く。前後に空白を入れない）
4. **「スクリプト プロパティを保存」** を押す

## 5. ウェブアプリとして出す（デプロイ）
1. 右上の青い **「デプロイ」** → **「新しいデプロイ」**
2. 左上の歯車（「種類の選択」）→ **「ウェブアプリ」**
3. 説明：空でよい。**次のユーザーとして実行：「自分」**。**アクセスできるユーザー：「全員」**（← ここを「全員」にしないと Worker から呼べません）
4. **「デプロイ」** を押す
5. 「アクセスを承認」と出る → **「アクセスを承認」** → お店の Google アカウントを選ぶ
6. **「このアプリは Google で確認されていません」** と出る（自分で作ったアプリなので出ます。こわくありません）
   → 左下の小さい **「高度な」** を押す（「詳細」ではありません）→ いちばん下の **「〇〇 予約メール（安全ではないページ）に移動」** を押す
7. 「〇〇 予約メール が Google アカウントへのアクセスをリクエストしています」→ 内容が **「ユーザーに代わってメールを送信する」だけ** であることを見て → **「許可」**
   - もし「Gmail のすべてのメールを閲覧・作成・送信・削除」と出たら、2 の appsscript.json が貼れていない。「キャンセル」で戻って 2 をやり直す
   - 許可のあと **「ファイルを開くことができません」** と出たら、アカウントが2つ入っているのが原因。シークレット ウィンドウで最初から
8. 「ウェブアプリ」の **URL**（https://script.google.com/macros/s/…/exec）が出る → **「コピー」** を押して、担当者に渡す（LINE などで送ってよい。合言葉がないと使えない）
9. 「完了」

## 6. 担当者がやること（お店はここまでで終わり）
- Cloudflare の秘密の変数に入れる：`cd ~/src/yoyaku-〇〇 && npx wrangler secret put GAS_URL`（5-8 の URL）と `npx wrangler secret put GAS_TOKEN`（合言葉）
- 手元で試すときは `.dev.vars` に `GAS_URL=…` と `GAS_TOKEN=…`（git には入らない）
- `public/shop.jsonc` の `mail` を、GAS を入れた Google のメールにする（確認メールの返信先・お店への知らせの宛先）

## つまずきやすい所（10/21 に実際に起きた3つは★）
- ★ **許可のあと「ファイルを開くことができません」** → Chrome にアカウントが2つ以上入っている。シークレット（かゲスト）のウィンドウで、お店の Google だけでログインして最初から
- ★ **許可の画面に「Gmail のすべてのメールを閲覧・作成・送信・削除」** → appsscript.json を貼る前にデプロイした。2 を先にやる。もう許可してしまったときは、Google アカウント → セキュリティ → 「サードパーティ製のアプリとサービス」→ 〇〇 予約メール → アクセス権を削除 → 2 から
- ★ **警告画面のボタンは「高度な」**（古い説明では「詳細」）。押すと下に「…（安全ではないページ）に移動」が出る
- **「アクセスできるユーザー」が「自分のみ」のまま** → Worker から呼ぶとログイン画面が返り、予約が「完了できませんでした」になる。「デプロイを管理」→ 鉛筆 → 「全員」に直して「デプロイ」
- **コードを直したあと** は、保存だけでは反映されない。「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」。URL は変わらない
- **合言葉が違う** → メールが来ず、予約は取り消されて「完了できませんでした」と出る。スクリプト プロパティの GAS_TOKEN と Cloudflare の GAS_TOKEN を見比べる
- **1日に送れる通数**：ふつうの Gmail は 1日 100 通（予約1件で2通）。小さなお店では足りる。足りなくなったら相談
- **迷惑メールに入る** ことがある。お客さんには「届かないときは迷惑メールを見てください」と案内。お店側は最初の1通を「迷惑メールではない」にしておく
- 動いているかの確かめ：5-8 の URL をブラウザで開くと `{"ok":true,"hello":"yoyaku mail"}` と出る（メールは送られない）
